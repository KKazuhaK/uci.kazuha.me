本章探讨我们如何判断一个搜索引擎是否好用：先从用户的角度出发，再看实验室测量（测试集合、相关性判断、日志，以及精确率与召回率），这些测量让工程师能够比较不同的排序方法。被评测的排序来自 检索模型：布尔、tf-idf 与向量空间 和 查询处理与高效 Top-K；用户本身则在 搜索引擎与 Web 中有所描述。

1. 用户对搜索引擎的期望

最主要的标准是返回页面的质量。 在经典 IR 中，它就是相关性 R(Q,D)R(Q, D)R(Q,D)；真实引擎的相关性则是 R(Q,D,… )R(Q, D, \dots)R(Q,D,…)（查询、文档以及更多因素），而它究竟如何定义，是各家引擎的机密之一。同样对用户很重要的还有：

  • 可信度
  • 去重（并提供"显示相似结果"选项）
  • 可读性
  • 快速访问
  • 没有弹窗

1.1 用户视角下的精确率与召回率

  • 精确率：最前面几条结果的相关程度如何？
  • 召回率：相关结果中有多少被展示了出来？

对网页搜索而言，精确率比召回率更重要。 尼尔森诺曼集团（Nielsen Norman Group）的眼动热力图显示，"关于我们"页、产品页和搜索结果页都呈现 F 形：视线先横扫顶部，再横扫一次，然后沿左边缘向下。用户只读顶部，多数人停在第一屏（85% 的人只看一屏结果；在 iProspect 调查中，41.2% 的人在第一页结束时放弃），因此最靠前的结果决定了质量。

召回率何时重要？当需要完整性时：此时的阅读方式是承诺式阅读模式（整页都会被读完），信源事先就值得信任，用户动机也很强。例如，法律和科学领域的搜索引擎。

📘 延伸阅读：Nielsen Norman Group（F 形结论背后的眼动研究）。精确率与召回率的精确集合定义见 §6。

📝 练习：§1.3

1.2 界面与工具

界面要好：简洁，不杂乱（可对比 Google、DuckDuckGo、Bing、Yandex、Baidu 和 Yahoo! 的首页）。此外还有前处理与后处理工具：

  • 拼写检查 / 自动纠正
  • 推荐的替代搜索
  • 指向资源的链接（地图、图片等）
  • 处理句法线索，例如在搜索框中输入的 URL 或数学公式

1.3 练习

精确率还是召回率？

对于通用的网页搜索引擎，精确率（前几条结果有多相关？）和召回率（展示了多少相关结果？）哪个更重要？什么时候召回率才是更重要的那一个？

解答

对于网页搜索，精确率更重要：用户按 F 形阅读，多数人只看第一屏（85% 的人只看一屏结果；iProspect 调查中 41.2% 的人在第一页结束时放弃），因此最靠前的结果决定质量。召回率在需要完整性时才重要：动机强的用户、可信的信源、承诺式阅读模式，即法律和科学领域的搜索引擎。

2. 有效性、效率与成本

评测总是相对于给定的查询、语料库和特定的相关性定义而言的：

  • 有效性衡量找到正确信息的能力，即排序与用户所期望的排序吻合得有多好。
  • 效率衡量完成这件事有多快，以及需要多少资源，即产生排序的方法所需的时间与空间。

评测是构建有效且高效的搜索引擎的关键：

  • 测量通常在受控的实验室实验中进行；也可以进行在线测试。
  • 有效性、效率和成本彼此相关：若要达到某一水平的有效性与效率，就决定了系统配置的成本；效率与成本的目标可能反过来影响有效性。

📘 延伸阅读：Croft §8.1 Why Evaluate?（书中第 297 页） · IIR 第 8 章 Evaluation in information retrieval

3. 测试集合与相关性判断

评测语料库让不同方法的结果可以相互比较。测试集合由文档、查询和相关性判断三部分组成，例如：

  • CACM：1958–1979 年《Communications of the ACM》的标题和摘要。查询与相关性判断由计算机科学家生成。
  • AP：1988–1990 年美联社新闻专线文档（来自 TREC 磁盘 1–3）。查询取自 TREC 主题 51–150 的 title 字段。主题与相关性判断由政府信息分析师生成。
  • GOV2：2004 年初从 .gov 域名网站爬取的网页。查询取自 TREC 主题 701–850 的 title 字段。主题与相关性判断由政府分析师生成。

4. 汇集

对集合中所有文档做穷尽式判断是不现实的（想想 GOV2 的 2500 万个网页 × 150 个主题）。GOV2 采用了汇集（pooling）技术：

  • 来自不同搜索引擎（或检索算法）排序的前 kkk 个结果（对 TREC 而言，kkk 在 50 到 200 之间）被合并为一个池。
  • 去除重复项。
  • 文档以某种随机顺序呈现给相关性评审员。

汇集为每个查询提供了大量的相关性判断，尽管仍然不完整；研究表明，系统之间的比较结果是准确的。

⚠️ 易错点：只有被汇集的文档会被判断，因此任何参与系统都没有排进前 kkk 名的相关文档，永远不会被判断。这就是汇集得到的判断"仍然不完整"的原因：它适合用来比较系统，而不是完整的相关文档清单。

5. 查询日志与点击数据

5.1 查询日志

查询日志既用于调优和评测搜索引擎，也用于查询建议等技术。它们可能引发隐私问题，因此要考虑是否对记录的数据做匿名化。典型内容包括：

  • 用户标识符或用户会话标识符
  • 查询词项，按用户输入的原样存储
  • 结果的 URL 列表、它们在结果列表中的排名，以及是否被点击
  • 时间戳：查询提交和点击等用户事件的时间
  • 用户点击了哪个页面

5.2 把点击当作偏好

点击不是相关性判断，尽管两者相关。点击会受多种因素的偏差影响，例如在结果列表中的排名（一种确认偏误：人们倾向于点击排在最上面的内容）。点击数据则可以用来预测文档对之间的偏好：

  • 与相关性判断相关；
  • 适用于具有多个相关等级、侧重用户相关性的任务；
  • 使用各种"策略"来生成偏好。

示例点击策略：Skip Above 与 Skip Next（Agichtein et al., 2006）。结果列表为 d1,d2,d3,d4d_1, d_2, d_3, d_4d1​,d2​,d3​,d4​，只有 d3d_3d3​ 被点击。生成的偏好为 d3>d2d_3 > d_2d3​>d2​、d3>d1d_3 > d_1d3​>d1​、d3>d4d_3 > d_4d3​>d4​：被点击的文档胜过它上方每一个未被点击的结果（用户跳过了它们），也胜过它正下方那个未被点击的结果。

📝 练习：§5.4

5.3 用点击偏差过滤噪声

单个用户的点击数据可能很嘈杂！ 但点击数据可以被聚合以消除噪声。点击分布信息可以找出频率高于预期的点击，这些点击与相关性高度相关，例如用点击偏差来过滤用于生成偏好的点击。

位置 ppp 上结果 ddd 的点击偏差 CD(d,p)CD(d, p)CD(d,p) 为：

CD(d,p)=O(d,p)−E(p)CD(d, p) = O(d, p) - E(p)CD(d,p)=O(d,p)−E(p)

O(d,p)O(d, p)O(d,p) 是在给定查询的所有实例上，文档 ddd 在排名位置 ppp 处的观察点击频率；E(p)E(p)E(p) 是在所有查询上平均的、排名 ppp 处的期望点击频率。用这个值来过滤点击，可以得到更可靠的信息（用于优化排序）。

📘 延伸阅读：Croft §8.3 Logging（书中第 305 页）

5.4 练习

Skip Above 与 Skip Next

结果列表为 d1,d2,d3,d4d_1, d_2, d_3, d_4d1​,d2​,d3​,d4​，用户只点击了 d3d_3d3​。Skip Above 与 Skip Next 会生成哪些偏好？

解答
  • Skip Above：用户在点击 d3d_3d3​ 之前看到并跳过了 d1d_1d1​ 和 d2d_2d2​，所以 d3>d2d_3 > d_2d3​>d2​ 且 d3>d1d_3 > d_1d3​>d1​。
  • Skip Next：点击之后紧邻的未被点击的结果，所以 d3>d4d_3 > d_4d3​>d4​。

因此得到 d3>d2d_3 > d_2d3​>d2​、d3>d1d_3 > d_1d3​>d1​、d3>d4d_3 > d_4d3​>d4​：这些都是排好序的文档对，而不是判定出的相关性。

def skip(ranking, clicked):
    prefs = []
    for c in clicked:
        i = ranking.index(c)
        for j in range(i):                      # Skip Above
            if ranking[j] not in clicked:
                prefs.append((c, ranking[j]))
        if i + 1 < len(ranking) and ranking[i + 1] not in clicked:   # Skip Next
            prefs.append((c, ranking[i + 1]))
    return prefs

print(skip(["d1", "d2", "d3", "d4"], {"d3"}))
[('d3', 'd1'), ('d3', 'd2'), ('d3', 'd4')]

6. 精确率、召回率与分类错误

精确率和召回率已在 §1.1 中从用户的角度出现过，这里给出它们的集合定义。设 AAA 为相关文档的集合，BBB 为检索到的文档的集合：

相关 不相关
检索到 A∩BA \cap BA∩B A‾∩B\overline{A} \cap BA∩B
未检索到 A∩B‾A \cap \overline{B}A∩B A‾∩B‾\overline{A} \cap \overline{B}A∩B
Recall=∣A∩B∣∣A∣Precision=∣A∩B∣∣B∣\text{Recall} = \frac{|A \cap B|}{|A|} \qquad\qquad \text{Precision} = \frac{|A \cap B|}{|B|}Recall=∣A∣∣A∩B∣​Precision=∣B∣∣A∩B∣​

A‾\overline{A}A 为不相关文档，B‾\overline{B}B 为未被检索到的文档。

  • 召回率：搜索引擎为某个查询找全所有相关文档的能力如何。
  • 精确率：它排除不相关文档的能力如何。

分类错误：

  • 假阳性（第一类错误）：检索到了一个不相关的文档（A‾∩B\overline{A} \cap BA∩B）。其比率即误报率（fallout）：
Fallout=∣A‾∩B∣∣A‾∣\text{Fallout} = \frac{|\overline{A} \cap B|}{|\overline{A}|}Fallout=∣A∣∣A∩B∣​
  • 假阴性（第二类错误）：相关但未被检索到的文档（A∩B‾A \cap \overline{B}A∩B）。占相关文档的比例即 1−召回率1 - \text{召回率}1−召回率。

⚠️ 易错点：分母决定一切。召回率除以所有相关文档（∣A∣|A|∣A∣），精确率除以所有检索到的文档（∣B∣|B|∣B∣），误报率除以所有不相关文档（∣A‾∣|\overline{A}|∣A∣）。误报率不等于 1−1 - 1− 精确率。

📘 延伸阅读：Croft §8.4.1 Recall and Precision（书中第 308 页） · IIR 第 8 章 Evaluation in information retrieval

6.1 练习

用手算精确率、召回率与误报率

某集合有 20 篇文档 d1,…,d20d_1,\dots,d_{20}d1​,…,d20​，相关的是 d1,d3,d5,d7,d9d_1, d_3, d_5, d_7, d_9d1​,d3​,d5​,d7​,d9​。引擎检索到了 d1,d2,d3,d4d_1, d_2, d_3, d_4d1​,d2​,d3​,d4​。请计算召回率、精确率和误报率，以及被漏掉的相关文档所占的比例。

7. 速查与五条要点

术语 含义
有效性 找到正确信息的能力（排序与用户期望一致）
效率 产生排序所需的时间和空间
测试集合 文档 + 查询 + 相关性判断（CACM、AP、GOV2）
TREC 主题 <num>、<title>（用作查询）、<desc>、<narr>
汇集 合并多个系统的前 kkk 个（505050–200200200），去重、打乱顺序后判断

点击偏差 CD(d,p)=O(d,p)−E(p)CD(d,p) = O(d,p) - E(p)CD(d,p)=O(d,p)−E(p)
召回率 ∣A∩B∣/∣A∣\lvert A\cap B\rvert / \lvert A\rvert∣A∩B∣/∣A∣
精确率 ∣A∩B∣/∣B∣\lvert A\cap B\rvert / \lvert B\rvert∣A∩B∣/∣B∣
误报率 ∣A‾∩B∣/∣A‾∣\lvert\overline{A}\cap B\rvert / \lvert\overline{A}\rvert∣A∩B∣/∣A∣（假阳性率）

必记的 5 条要点

  1. 网页用户按 F 形阅读，且很早就停下，所以对网页搜索而言，精确率最重要；只有在需要完整性时（法律、科学），召回率才重要。
  2. 有效性（找到正确答案）、效率（时间与空间）和成本相互权衡；评测大多在受控的实验室实验中完成。
  3. 测试集合是文档 + 查询 +（多为二元的）相关性判断；由于全部判断不现实，汇集只对合并后的前 kkk 个结果做判断。结果不完整，但比较是准确的。
  4. 点击受排名影响，且不是相关性判断；把它们当作成对的偏好（Skip Above 与 Skip Next），并用点击偏差 O(d,p)−E(p)O(d,p) - E(p)O(d,p)−E(p) 过滤噪声。
  5. 召回率 =∣A∩B∣/∣A∣= |A\cap B|/|A|=∣A∩B∣/∣A∣，精确率 =∣A∩B∣/∣B∣= |A\cap B|/|B|=∣A∩B∣/∣B∣，误报率 =∣A‾∩B∣/∣A‾∣= |\overline{A}\cap B|/|\overline{A}|=∣A∩B∣/∣A∣；假阴性为 1−1 - 1− 召回率，而误报率不等于 1−1 - 1− 精确率。
